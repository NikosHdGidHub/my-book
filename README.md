# Название книги

> Короткий логлайн в одну-две строки.

## Структура

- `manuscript/` — текст книги (ТЕЛО)
- `outline/` — планы, арки, биты (СКЕЛЕТ)
- `notes/` — идеи, куски, диалоги
- `resources/` — фактура, референсы, картинки
